K-Line ECU Reader: ESP32-S3 OBD-II K-Line live data & DTC scanner

An open-source diagnostic tool for older cars without CAN. An ESP32-S3 with a 2.1" round touch screen talks to the engine ECU over the K-Line (ISO 9141-2 / ISO 14230-4 KWP2000) through an L9637D. It shows live data and the full vehicle PID profile, and reads and clears trouble codes. No ELM327, no phone, no app.

Source code on GitHub Hardware build guide (TR)

Features

Native K-Line stack

KWP2000 fast init, 5-baud init for ISO 9141-2 and KWP2000, automatic protocol detection with line diagnostics.

Full vehicle profile

Every supported SAE J1979 mode 01 PID (01–5F) with name, unit, live value and refresh interval.

Trouble codes

Read stored DTCs with descriptions. Clear codes and the check engine light with a two-tap confirmation.

Screen-aware polling

The values you are looking at are polled first. Silent PIDs drop out, and static ones are read once.

Fuel consumption

L/h and L/100 km from PID 5E, from MAF, or by speed-density from MAP, IAT and RPM.

Low-latency display

LVGL on a 480×480 RGB panel with double frame buffers. It redraws as soon as the ECU answers.

Tested on a Chevrolet / Daewoo Kalos 1.4 16V. It should work on any car with OBD-II pin 7 (K-Line) and no CAN, which covers many petrol cars built roughly between 2001 and 2008.

Logic level shifter3.3 V ↔ 5 V between the ESP and the L9637D
L78L05, 1N4005, 510 Ω, 2 × 100 nF5 V supply, protection, K pull-up, decoupling
OBD-II plugpins 4/5 GND, 7 K-Line, 16 +12 V

K TX is GPIO44 (the header's RXD) and K RX is GPIO43 (the header's TXD). Power and flash through the "USB" USB-C port, and keep the "UART" USB-C port unplugged.

Build

idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor

How fast is K-Line?

At 10400 baud, with a 55 ms minimum gap between an answer and the next request (ISO 14230-4), each PID takes about 130–150 ms. That is about 7 requests per second. The firmware spends them on the values on screen; a single gauge refreshes about every 0.3 s.

Türkçe: ESP32 ile K-Line OBD-II okuyucu

CAN hattı olmayan eski araçlarda (çoğunlukla 2001–2008 arası benzinli modeller) OBD-II soketinin 7. pinindeki K-Line üzerinden motor beynine doğrudan bağlanan açık kaynak bir proje. ESP32-S3 ve L9637D ile canlı veri, araç profili (desteklenen bütün PID'ler ve yenilenme süreleri) ve arıza kodu okuma/silme yapar. Bütün veriler 2.1" yuvarlak dokunmatik ekranda görünür; ELM327 gerekmez. Chevrolet / Daewoo Kalos 1.4 16V'de denendi. Montaj için Türkçe montaj rehberine bakın.
